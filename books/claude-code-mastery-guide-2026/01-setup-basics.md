# セットアップと基本操作

この章では、Claude Codeのインストールから基本的な使い方まで、実際に手を動かしながら学んでいきます。Claude Codeを使い始めるための第一歩として、環境構築と基本コマンドをマスターしましょう。

## インストール方法

Claude Codeは、複数のプラットフォームとインストール方法に対応しています。お使いの環境に合わせて、最適な方法を選択してください。

### macOS / Linux / WSL

最も簡単な方法は、公式のインストールスクリプトを使用する方法です。ターミナルで以下のコマンドを実行します。

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

このスクリプトは、自動的に最新版のClaude Codeをダウンロードし、システムにインストールします。インストールが完了すると、`claude`コマンドがすぐに使えるようになります。

### Homebrew（macOS / Linux）

Homebrewを使用している場合は、以下のコマンドでインストールできます。

```bash
brew install --cask claude-code
```

Homebrewを使用すると、アップデート管理も簡単に行えます。

### Windows

Windowsユーザーには、PowerShellまたはコマンドプロンプトでインストールスクリプトを実行する方法があります。

PowerShellで以下を実行します。

```powershell
irm https://claude.ai/install.ps1 | iex
```

または、コマンドプロンプトで公式インストーラーをダウンロードして実行する方法もあります。

### WinGet（Windows）

Windows Package Manager（WinGet）を使用している場合は、以下のコマンドで簡単にインストールできます。

```bash
winget install Anthropic.ClaudeCode
```

WinGetを使用すると、他のアプリケーションと同様に一元管理できます。

### インストールの確認

インストールが正常に完了したか確認するには、ターミナルで以下のコマンドを実行します。

```bash
claude --version
```

バージョン番号が表示されれば、インストールは成功です。

## 認証とログイン

Claude Codeを使用するには、Anthropicアカウントでの認証が必要です。

### ログインの実行

初めてClaude Codeを使用する際は、以下のコマンドで認証を行います。

```bash
claude auth login
```

このコマンドを実行すると、ブラウザが自動的に開き、認証画面が表示されます。以下の2つの方法でログインできます。

1. **Claude.ai アカウント**: 通常のClaudeを使用しているアカウントでログイン
2. **Anthropic Console アカウント**: API利用などで使用しているアカウントでログイン

ブラウザで認証を完了すると、ターミナルに戻り、「ログインに成功しました」というメッセージが表示されます。

### 認証状態の確認

現在の認証状態を確認するには、以下のコマンドを使用します。

```bash
claude auth status
```

このコマンドは、ログイン中のユーザー情報や認証の有効期限などを表示します。

JSON形式で出力したい場合は、以下のオプションを追加します。

```bash
claude auth status --json
```

この形式は、スクリプトや自動化ツールと連携する際に便利です。

### ログアウト

別のアカウントに切り替えたい場合や、セキュリティのためにログアウトしたい場合は、以下のコマンドを使用します。

```bash
claude auth logout
```

## 基本操作

認証が完了したら、いよいよClaude Codeを使い始めましょう。基本的な操作方法を順番に見ていきます。

### インタラクティブセッションの開始

最もシンプルな使い方は、`claude`コマンドを実行することです。

```bash
claude
```

このコマンドを実行すると、インタラクティブセッションが開始され、Claudeとの対話形式で作業を進めることができます。プロンプトが表示され、質問やタスクを入力できる状態になります。

### 初期プロンプト付きセッション

セッション開始時に最初の質問やタスクを指定したい場合は、以下のように実行します。

```bash
claude "このディレクトリにあるPythonファイルのテストコードを作成して"
```

ダブルクォートで囲んだプロンプトを指定すると、セッション開始と同時にClaude Codeがタスクを実行し始めます。

### 非インタラクティブ実行

対話形式ではなく、1つのタスクを実行して結果を取得したい場合は、`-p`オプションを使用します。

```bash
claude -p "このコードの問題点を教えて"
```

このモードでは、Claudeが応答を返した後、セッションは自動的に終了します。スクリプトやCI/CDパイプラインに組み込む際に便利です。

### パイプ入力の活用

標準入力からデータを受け取ることもできます。これにより、ファイルの内容を直接Claudeに送ることができます。

```bash
cat app.py | claude -p "このコードをリファクタリングして"
```

または、複数のファイルを結合して送ることも可能です。

```bash
cat *.js | claude -p "この関数群の依存関係を図示して"
```

パイプを使うことで、既存のUnixツールとシームレスに連携できます。

### 最新会話の継続

作業を中断した後、最後のセッションを継続したい場合は、`-c`オプションを使用します。

```bash
claude -c
```

このコマンドは、最も新しい会話の続きから開始します。前回のコンテキストを保持したまま作業を続けられるため、効率的に開発を進められます。

### セッションの再開

特定の名前を付けたセッションを再開したい場合は、`-r`オプションを使用します。

```bash
claude -r "my-feature"
```

このコマンドは、"my-feature"という名前のセッションを再開します。複数のプロジェクトを並行して進めている場合に便利です。

### アップデート

Claude Codeを最新版にアップデートするには、以下のコマンドを実行します。

```bash
claude update
```

新機能やバグ修正が含まれている可能性があるため、定期的にアップデートすることをお勧めします。

## セッション管理

Claude Codeでは、複数のセッションを管理することができます。プロジェクトごとにセッションを分けることで、コンテキストを整理し、効率的に作業を進められます。

### セッション名の付け方

新しいセッションに名前を付けて開始するには、`-n`オプションを使用します。

```bash
claude -n "my-feature"
```

セッション名は、以下のような命名規則を推奨します。

- プロジェクト名を含める: `project-feature-name`
- 短く分かりやすく: `auth-refactor`、`api-bugfix`
- 日付を含める: `2026-03-18-performance-fix`

わかりやすい名前を付けることで、後から再開する際に混乱を避けられます。

### セッションの一覧表示

現在保存されているセッションの一覧を確認するには、以下のコマンドを使用します。

```bash
claude sessions list
```

このコマンドは、すべてのセッション名と最終更新日時を表示します。

### セッションの再開

前述の通り、特定のセッションを再開するには`-r`オプションを使用します。

```bash
claude -r "api-bugfix"
```

セッション名がわからない場合は、まず`claude sessions list`で一覧を確認してから再開すると良いでしょう。

### セッションの分岐

既存のセッションをベースに、新しいセッションを開始したい場合は、`--fork-session`オプションを使用します。

```bash
claude --fork-session "original-session" -n "new-experiment"
```

このコマンドは、"original-session"の状態をコピーして、"new-experiment"という新しいセッションを作成します。異なるアプローチを試したい場合や、実験的な変更を行う際に便利です。

### セッションの削除

不要になったセッションを削除するには、以下のコマンドを使用します。

```bash
claude sessions delete "session-name"
```

定期的に古いセッションを整理することで、管理が容易になります。

## 利用環境

Claude Codeは、様々な環境で利用できます。それぞれの特徴を理解し、用途に応じて使い分けましょう。

### Terminal CLI

本章で主に説明してきたのが、ターミナルでのCLI利用です。

**メリット**:
- 既存のコマンドラインツールと統合しやすい
- SSH経由のリモートサーバーでも使用可能
- スクリプト化や自動化が容易
- 軽量で高速

**使用例**:
- サーバー管理作業
- CI/CDパイプラインへの組み込み
- 複数のファイルを一括処理

### VS Code統合

Visual Studio Codeの拡張機能として、Claude Codeを使用できます。

**メリット**:
- エディタ内でコード生成や質問ができる
- 現在開いているファイルのコンテキストを自動で認識
- インラインでの提案やリファクタリング
- GUIで操作しやすい

**インストール方法**:
VS Code拡張機能マーケットプレイスで「Claude Code」を検索してインストールします。

**使用例**:
- コードレビューや説明の生成
- リファクタリングの提案
- テストコードの生成

### JetBrains統合

IntelliJ IDEA、PyCharm、WebStormなどのJetBrains製IDEでも使用できます。

**メリット**:
- IDEの強力なコード解析機能と組み合わせられる
- プロジェクト構造を理解したサポート
- デバッグ情報との連携

**インストール方法**:
JetBrains Marketplace（Plugins設定）で「Claude Code」を検索してインストールします。

**使用例**:
- 大規模プロジェクトでのナビゲーション
- 複雑なリファクタリング
- フレームワーク固有のコード生成

### Desktop App

Claude CodeにはElectronベースのデスクトップアプリケーションもあります。

**メリット**:
- グラフィカルなインターフェース
- ファイルのドラッグ&ドロップ対応
- 視覚的なセッション管理
- プレビュー機能

**インストール方法**:
公式サイトからインストーラーをダウンロードして実行します。

**使用例**:
- CLIに不慣れなユーザー
- 視覚的なフィードバックが欲しい場合
- プレゼンテーションでのデモ

### Web版

ブラウザ上でClaude Codeの機能を使用することもできます。

**メリット**:
- インストール不要
- どの環境からでもアクセス可能
- 常に最新版を使用できる
- クロスプラットフォーム

**アクセス方法**:
[https://claude.ai/code](https://claude.ai/code) にアクセスします。

**使用例**:
- インストールできない環境での一時的な使用
- 複数デバイス間での作業
- 学習や試用段階

## まとめ

| 項目 | コマンド/方法 | 用途 |
|------|--------------|------|
| インストール | `curl -fsSL https://claude.ai/install.sh \| bash` | macOS/Linux/WSL |
| インストール | `brew install --cask claude-code` | Homebrew |
| インストール | `winget install Anthropic.ClaudeCode` | Windows |
| ログイン | `claude auth login` | 初回認証 |
| 認証確認 | `claude auth status` | ログイン状態の確認 |
| セッション開始 | `claude` | インタラクティブモード |
| プロンプト付き | `claude "query"` | 初期プロンプト指定 |
| 非インタラクティブ | `claude -p "query"` | 1回限りの実行 |
| パイプ入力 | `cat file \| claude -p "query"` | ファイル内容の送信 |
| 最新会話継続 | `claude -c` | 前回の続きから |
| セッション再開 | `claude -r "name"` | 名前付きセッション再開 |
| セッション命名 | `claude -n "name"` | 新規セッションに名前付け |
| セッション分岐 | `claude --fork-session "name"` | セッションのコピー作成 |
| アップデート | `claude update` | 最新版へ更新 |
