## Claude Codeを「使っている」——でも「使いこなしている」とは言えない

Claude Codeをインストールして、コードの質問をする。ファイルを編集してもらう。便利だ。

でも、こんなことを思ったことはありませんか？

**「毎回同じことを説明している」「もっと賢く動いてほしい」「チームで使いたいけど、どう設定すればいいか分からない」**

Claude Codeには、日常的な対話だけでは触れない機能が数多くあります。CLAUDE.md、hooks、Skills、MCP、Agent SDK——これらを組み合わせることで、Claude Codeは「チャットで質問するツール」から**「プロジェクトを理解して自律的に動くAIパートナー」**に変わります。

---

**でも、体系的に学ぶ手段がない。**

よく聞く悩みをまとめると：

- CLAUDE.mdの書き方がよく分からない。何を書けばいいのか
- hooksやSkillsの存在は知っているが、設定方法が分からない
- MCPサーバーを導入したいが、どこから手をつければいいか
- Agent SDKでClaude Codeをプログラムから制御したいが、資料がない
- コンテキストウィンドウを意識した使い方ができていない
- チームやCIで使いたいが、運用設計のノウハウが不足している
- 月額コストが読めない。最適化する方法を知りたい

**そこで、Claude Codeの全機能を基礎から実践まで体系的にカバーするマスターガイドを執筆しました。**

## 本書の内容を一部紹介

### CLAUDE.mdでプロジェクトの「頭脳」を定義する

毎回「このプロジェクトは2スペースインデントで…」と説明していませんか？ CLAUDE.mdに書いておけば、セッション開始時に自動で読み込まれます。

```markdown
# プロジェクト概要
TypeScript + Next.js 15のWebアプリ。App Router使用。

# コーディング規約
- インデント: 2スペース
- コミットメッセージ: Conventional Commits形式
- テスト: 変更したファイルには必ずテストを書く

# 禁止事項
- .envファイルの内容をコミットしない
- main直pushしない
```

本書では、プロジェクト・ユーザー・組織レベルの使い分けから、実践的なテンプレートまで詳しく解説しています。

### hooksでツール実行を自動化する

Claude Codeがファイルを編集するたびに、自動でlintを走らせたい。コミット前に必ずテストを実行したい。hooksを使えば、それが可能になります。

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "command": "npx eslint --fix $CLAUDE_FILE_PATH"
      }
    ]
  }
}
```

本書では、メモリ監視、ログ記録、品質チェックなど、実運用で使えるhooksパターンを多数紹介しています。

### MCPで外部ツールに直接アクセスする

Playwright、Obsidian、Supabase——Claude Codeから直接これらのツールを操作できます。MCPサーバーの導入方法から自作まで、段階的に学べます。
